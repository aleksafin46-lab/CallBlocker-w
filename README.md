# OnlyContacts — блокировка входящих вызовов не из телефонной книги

Android-приложение для Samsung Galaxy S25 FE и других устройств Android 10+.

## Что делает
- Пропускает входящие вызовы с номеров, найденных в контактах.
- Отклоняет входящие вызовы с номеров, которых нет в контактах.
- Отклоняет вызовы со скрытым/неопределённым номером.
- Не фильтрует исходящие вызовы.
- Если нет разрешения на чтение контактов или произошла ошибка чтения базы, приложение пропускает вызов, чтобы случайно не заблокировать важный звонок.

## Сборка
1. Установите Android Studio.
2. Откройте в Android Studio папку `OnlyContacts`.
3. Дождитесь синхронизации Gradle.
4. Выберите **Build → Build Bundle(s) / APK(s) → Build APK(s)**.
5. APK появится в `app/build/outputs/apk/debug/`.

Требуется JDK 17 и Android SDK 35.

## Установка и включение на телефоне
1. Установите APK.
2. Откройте «Только контакты».
3. Нажмите «Включить блокировку».
4. Разрешите доступ к контактам.
5. Подтвердите системный запрос на роль приложения для фильтрации вызовов.

Android/Samsung может показывать управление этой ролью в настройках приложений по умолчанию. Одновременно такую роль может иметь только одно приложение.

## Важно
- Это исходный проект, а не готовый APK.
- Android может показывать отдельные системные уведомления или журналировать отклонённые вызовы в зависимости от версии One UI.
- Номера в международном и локальном формате сопоставляются через `PhoneNumberUtils.compare`; качество сопоставления зависит от формата номера и региональных правил.
- Перед повседневным использованием проверьте приложение с несколькими тестовыми звонками: один номер сохранён в контактах, один не сохранён и один со скрытым номером.
- Для публикации в Google Play потребуются дополнительные проверки политик и деклараций разрешений.
